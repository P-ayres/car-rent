# SIstema de locação de veiculos
### *Um sistema simples de locação de veiculos automotivos* 

[![Python](https://img.shields.io/badge/Python-Django-blue)](https://www.djangoproject.com/)
[![Board](https://img.shields.io/badge/Development-Board-purple)](https://github.com/users/P-ayres/projects/5/views/1)


#### Um sistema desenvolvido em Django como requisito obrigatório para a aprovação na cadeira de desenvolvimento full stack

---

</div>

> - Gerencie e realize a locação de veiculos categorizados por tipo
> - Cadastre e gerencie veiculos, definindo tipo (SUV, ECONOMICO, ETC)
> - Gerencie o estado dos veiculos cadastrando e acompanhando a manuteção dos mesmos
> - Gerencie o fluxo de locação com suas respectivas taxas por categoria
> - Gerenciamento de usuários com roles de admin e funcionarios
> - Exportação de relátorios operacionais

## Para rodar o projeto

```
na pasta do projeto: uv sync
cd g2
uv run python manage.py runserver
```
